# MD工具箱 — 需求分析文档

## 1. 项目概述

### 1.1 项目背景

面向开发者、技术写作者和知识管理用户，打造一款轻量、高性能的 Markdown 文件编辑与预览工具箱，提供"所见即所得"的实时编辑体验。

### 1.2 项目目标

- 提供流畅的 Markdown 文件读写能力
- 实现编辑区与预览区的实时同步渲染
- 支持 LaTeX 数学公式等扩展语法
- 编辑后保持预览区滚动位置不变
- 支持多套主题切换

### 1.3 目标用户

- 技术文档编写者
- 笔记/知识库管理用户
- 需要公式渲染的学生/研究人员

## 3. 非功能性需求

### 3.1 性能

| 指标 | 目标值 |
|------|--------|
| 启动时间 | < 2s（冷启动） |
| 编辑到渲染延迟 | < 300ms（含公式渲染） |
| 大文件支持 | 10万行内无明显卡顿 |
| 内存占用 | 空闲 < 200MB |

### 3.2 兼容性

- **操作系统**: Windows 10/11（一期），后续扩展 macOS / Linux
- **架构**: x64，后续扩展 ARM64

### 3.3 可用性

- 界面语言：中文（一期），后续国际化
- 快捷键遵循 VSCode 习惯（Ctrl+B 加粗、Ctrl+I 斜体 等）

## 4. 架构质量需求

### 4.1 模块高内聚

系统强制划分为以下独立模块，每个模块内部职责单一、边界清晰：

| 模块 | 唯一职责 | 内部变更不应影响 |
|------|----------|------------------|
| 文件管理 | 文件的打开、新建、保存、最近记录等 I/O 操作 | 编辑、渲染、UI 布局 |
| 编辑核心 | 文本输入、语法高亮、光标管理、撤销重做 | 文件存储方式、渲染管线、主题样式 |
| 渲染管线 | 接收 Markdown 文本，输出可展示内容（含公式、图表等子渲染器） | 编辑器实现、文件来源、布局方式 |
| 主题引擎 | 管理配色方案，向编辑区和预览区统一分发样式变量 | 编辑逻辑、渲染逻辑、文件操作 |
| 布局管理 | 分屏比例、视图模式切换、面板显隐 | 编辑内容和渲染结果 |
| 导出服务 | 接收渲染结果，输出为指定格式文件 | 编辑器和渲染器内部实现 |
| AI 桥接层 | 管理 AI 后端连接与协议适配，提供统一的 AI 调用接口 | 编辑器 UI、AI 后端具体实现 |

**内聚性要求**：每个模块的公开 API 不超过 5 个核心接口；模块内部逻辑变更时，仅需修改该模块自身代码。

### 4.2 模块低耦合

| 编号 | 要求 | 说明 |
|------|------|------|
| C1 | 接口隔离 | 模块之间仅通过抽象接口（而非具体类/对象）通信，编辑核心不知道渲染管线使用什么库 |
| C2 | 数据单向流动 | 数据流向为：文件 → 编辑核心 → 渲染管线 → 预览视图，不存在反向依赖 |
| C3 | 事件总线解耦 | 模块间状态同步使用事件总线，事件发送方不关心接收方是否存在或数量 |
| C4 | 可替换性 | 任一模块可被独立替换为另一实现（如换编辑器内核），其余模块无需改动 |

### 4.3 可扩展性

| 编号 | 扩展点 | 要求 |
|------|--------|------|
| E1 | 语法扩展 | 新增 Markdown 语法（如自定义容器、属性语法）时，只需注册新解析器，不修改渲染管线核心 |
| E2 | 公式引擎 | 公式渲染器为可插拔组件，允许在 KaTeX / MathJax / 自定义引擎之间切换 |
| E3 | 代码高亮 | 预览区代码块高亮支持扩展新语言（语法文件注册），不影响主流程 |
| E4 | 主题扩展 | 新增主题只需提供一份主题描述文件（如 JSON 配置），零代码改动 |
| E5 | 导出格式 | 新增导出目标格式时，只需添加新导出适配器，不修改渲染逻辑 |
| E6 | 图表语法 | Mermaid / PlantUML 等图表渲染为独立插件，按需加载 |
| E7 | 快捷键 | 所有快捷键支持用户自定义绑定，不硬编码 |
| E8 | AI 后端 | AI 桥接层为协议无关设计，新增 AI 协议（如 Anthropic、本地模型）只需新增适配器，不影响编辑器和对话面板 |

### 4.4 安装部署要求

| 编号 | 要求 | 描述 |
|------|------|------|
| D1 | 便携模式 | 测试开发阶段支持免安装直接运行（非打包的目录模式） |
| D2 | 安装包 | 正式发布时提供标准安装包（Windows 下为 msi/exe），支持自定义安装路径 |
| D3 | 离线可用 | 所有核心渲染资源（KaTeX 字体/JS、语法高亮文件）打包内置，不依赖外部 CDN |
| D4 | 安装包体积 | 正式版安装包 ≤ 150MB，便携版 ≤ 200MB |
| D5 | 用户数据隔离 | 用户配置（主题、快捷键、最近文件列表）存储于用户目录，与安装目录分离，便于升级 |

## 6. 验收标准

1. 打开 1MB 大小的 `.md` 文件，编辑到预览延迟 ≤ 300ms
2. 包含 ≥ 50 个 LaTeX 公式的文档，流畅无卡顿
3. 在文档中间位置编辑后，预览区滚动位置不跳变
4. 浅色/深色主题一键切换，预览区同步更新
5. 无网络环境下所有核心功能正常（渲染资源离线内置）
6. 安装包大小 ≤ 150MB
7. AI 生成的文档修改以 diff 形式展示，用户可逐条接受/拒绝
8. AI 的所有文档写入操作均可通过 Ctrl+Z 一步撤销
9. 替换 AI 后端（如从 OpenAI 换为兼容协议的第三方服务）仅需修改配置，无需代码改动
