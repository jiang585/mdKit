### 1.3 模块约束规则

| 规则 | 说明 |
|------|------|
| 入口出口 | 每个模块通过 `index.ts` 暴露 ≤5 个核心接口，禁止导入模块内部文件 |
| 单向依赖 | `shared/` 不引用任何模块代码；模块可引用 `shared/` |
| 测试隔离 | 测试可直接导入模块内部文件（ESLint 对测试目录豁免 `no-restricted-imports`） |
| 循环依赖 | CI 配置 `import/no-cycle`，最大深度 6 |

## 2. 核心模块接口契约

### 2.1 编辑核心 (editor)

```
createEditor(options: EditorCreateOptions): EditorHandle
```

| 接口 | 签名 |
|------|------|
| `getText()` | `() => string` |
| `setText(text, source)` | `(text: string, source: EditSource) => void` |
| `getRevision()` | `() => number` |
| `captureState()` / `restoreState(state)` | 多标签页状态保存/恢复 |
| `setOptions(opts)` | 动态更新行号/换行/快捷键 |

编辑器内部通过 CodeMirror 6 的 `Compartment` 实现选项热替换，不重建 EditorView。

### 2.2 渲染管线 (preview)

```
createRenderScheduler(options: SchedulerOptions): RenderScheduler
PreviewPanel(props: PreviewPanelProps): JSX.Element
renderMarkdownOnce(req: RenderRequest): Promise<RenderResult>
```

| 接口 | 签名 |
|------|------|
| `request()` | `() => void` — 防抖触发渲染 |
| `flush()` | `() => void` — 立即渲染 |
| `dispose()` | `() => void` |

渲染管线内部流程：

```
getSnapshot() → debounce(120ms) → ensureWorker()
  → Worker: render.worker.ts
    → pipeline.ts (unified)
      → remark-parse → remark-gfm → remark-math
      → remark-rehype → rehype-sanitize
      → postProcessPlugin (锚点/TOC/图片)
      → rehype-katex → rehype-highlight → rehype-stringify
    → postMessage({ type: 'result', res })
  → deliver (修订号淘汰)
  → PreviewPanel: captureAnchor → innerHTML = result → restoreScrollTop
```

Worker 加载失败时的降级路径（本次修复新增）：

```
ensureWorker() → Worker onerror
  → workerUnavailable = true
  → renderOnMainThread(pendingRequest)  // 动态 import pipeline 到主线程
  → 本次会话不再尝试 Worker
```

### 2.3 主题引擎 (theme)

```
createThemeEngine(): ThemeEngineApi
validateTheme(raw: unknown): ThemeValidation
```

| 接口 | 签名 |
|------|------|
| `init(editorThemeId, previewThemeId)` | `=> Promise<AppliedTheme>` |
| `list()` | `() => ThemeSummary[]` |
| `setTheme({ editorThemeId?, previewThemeId?, linked })` | `=> Promise<AppliedTheme>` |
| `nextTheme(linked)` | `=> Promise<AppliedTheme>` |
| `previewVars()` | `() => Record<string, string>` |

主题数据流：

```
JSON 主题文件 → Zod safeParse → ThemeRegistry
  → applyThemes() → applyVars(root, scopeVars)
  → document.documentElement.style.* = 值
  → CSS 变量 → 所有组件消费
```

Zod 校验替代 Ajv（本次修复）：避免了 `unsafe-eval` 被 CSP 拦截的问题，同时将 `ajv` 从 dependencies 移除。

### 2.4 布局管理 (layout)

```
SplitPane(props: SplitPaneProps): JSX.Element
useLayoutStore: Zustand store
```

| 状态 | 类型 | 说明 |
|------|------|------|
| `mode` | `'split' \| 'editor' \| 'preview'` | 显示模式 |
| `ratio` | `number (0.1–0.9)` | 分屏比例 |
| `tocVisible` | `boolean` | 目录面板 |
| `aiPanelVisible` | `boolean` | AI 面板 |

### 2.5 导出服务 (export)

| 接口 | 说明 |
|------|------|
| `exportAsHtml(input)` | 渲染 Markdown → 内嵌 HTML |
| `exportAsPdf(input)` | 渲染 → HTML → Electron printToPDF |

两接口均通过 `renderMarkdownOnce`（同步调用管线函数，不走 Worker）获取 HTML。

### 2.6 AI 桥接层 (ai)

| 接口 | 说明 |
|------|------|
| `ai-store.ts` | Zustand 分片：对话状态、流式响应、配置文件管理 |
| `ChatPanel.tsx` | 对话模式 + 文档编辑模式 |
| `InlineAssist.tsx` | 选区行内辅助 |
| `DiffView.tsx` | AI 修改的 diff 预览 + 逐条接受/拒绝 |

AI 请求经 preload → `IPC.aiChatStart` → 主进程 `ai-service.ts` → OpenAI 兼容 HTTP API。

密钥使用 `safeStorage` 加密存储，不进入 `config.json` 或日志。

## 3. IPC 契约

### 3.1 通道总览

| 分类 | 通道 | 方向 | 载荷校验 |
|------|------|------|----------|
| 文件 | `file:open-dialog` | invoke | 无 |
| | `file:read` | invoke | `{ path }` |
| | `file:open-dropped` | invoke | `{ path }`（正则校验 .md） |
| | `file:save` | invoke | `{ path, content }` |
| | `file:save-as` | invoke | `{ defaultName, content }` |
| | `file:recent-list` | invoke | 无 |
| | `file:recent-clear` | invoke | 无 |
| 配置 | `config:get` | invoke | 无 |
| | `config:patch` | invoke | `UserConfigPatch`（Zod） |
| 主题 | `theme:import` | invoke | 无 |
| | `theme:list-custom` | invoke | 无 |
| 导出 | `export:html` | invoke | `{ defaultName, html }` |
| | `export:pdf` | invoke | `{ defaultName, html }` |
| 系统 | `shell:open-external` | invoke | `{ url }`（URL 校验） |
| | `window:set-title` | invoke | `{ title, documentPath, dirty }` |
| 草稿 | `draft:save` | invoke | `{ tabId, path, content }` |
| | `draft:clear` | invoke | `{ tabId }` |
| | `draft:list` | invoke | 无 |
| 日志 | `log:renderer-error` | invoke | `{ message, stack? }` |
| AI | `ai:chat-start` | invoke | `{ requestId, profileId, messages, ... }` |
| | `ai:chat-cancel` | invoke | `{ requestId }` |
| | `ai:secret-set` | invoke | `{ profileId, apiKey }` |
| | `ai:secret-status` | invoke | `{ profileId }` |
| | `ai:test-connection` | invoke | `{ profileId }` |
| 推送 | `menu:command` | send → 渲染 | `{ command }` |
| | `app:open-path` | send → 渲染 | `OpenedFile` |

### 3.2 安全规则

- 所有 invoke 通道通过 `ipcMain.handle` 注册，入站载荷经 Zod `safeParse` 校验
- 校验失败记录警告日志，返回错误（不泄露细节）
- 文件路径白名单：只允许经系统对话框、拖拽授权、最近文件列表或命令行参数传入的路径
- 渲染进程无法直接调用 `ipcRenderer`（preload 仅暴露白名单方法）

### 3.3 权限边界

```
文件路径授权流程：

  系统对话框 ──grant──▶ grantedPaths Set ──assertGranted──▶ read/save
  拖拽文件   ──grant──▶ grantedPaths Set
  最近文件   ──grant──▶ grantedPaths Set (批量)
  命令行参数 ──grant──▶ grantedPaths Set
```

## 4. 核心数据流时序

### 4.1 编辑 → 预览

```
User Input
  → CodeMirvew dispatch (修订号 +1)
  → onContentChanged({ revision, source })
  → scheduler.request()
  → debounce(120ms)
  → getSnapshot(): { markdown, revision, docPath }
  → Worker.postMessage({ type: 'render', req })
  → Worker: pipeline.ts → HTML + anchors
  → Worker: postMessage({ type: 'result', res })
  → deliver(res)  // 丢弃 revision ≤ delivered 的结果
  → PreviewPanel useEffect([result])
    → captureAnchor(scrollTop, blocks)
    → content.innerHTML = result.html
    → restoreScrollTop(anchor, newBlocks)
```

### 4.2 文件打开

```
用户操作 (菜单/拖拽/快捷键)
  → menu:command → handleMenuCommand('file.open')
  → bridge().file.openDialog()
  → IPC: file:open-dialog
  → Main: dialog.showOpenDialog()
  → grantPath(filePath)
  → readGrantedFile(): { path, name, content }
  → return to renderer
  → openFileAsTab(file)
    → documentStore.openAsTab(path, name)
    → editorHandle.setText(content, 'file-load')
    → scheduler.flush()
```

### 4.3 文件保存

```
用户操作 (Ctrl+S)
  → menu:command → handleMenuCommand('file.save')
  → saveActive()
    → 有路径: bridge().file.save(path, text)
    → 无路径: bridge().file.saveAs(name, text)
  → IPC → Main: assertGranted(path) → writeFile
  → touchRecentFile()
  → markDirty(false) → clearDraft()
```

### 4.4 主题切换

```
用户操作 (菜单/快捷键)
  → menu:command → handleMenuCommand('theme.next')
  → themeEngine.nextTheme(linked)
    → registry.nextIdAfter(currentId)
    → applyThemes(registry, nextEditorId, nextPreviewId)
      → applyVars(root, editorScopeVars(theme))
      → applyVars(root, previewScopeVars(theme))
      → root.dataset.mkKind = theme.kind
    → persist()
      → bridge().config.patch({ theme: { editorThemeId, previewThemeId } })
```

## 5. AI 桥接层设计

### 5.1 架构

```
渲染进程                   主进程                 外部 API
ChatPanel                   ai-service.ts
  ├── ai-store (Zustand)    ├── safeStorage       → OpenAI 兼容
  ├── prompt-context        ├── HTTP(S) 请求        HTTP API
  ├── redact                └── 密钥管理
  └── DiffView
```

### 5.2 协议适配

- 支持任何 OpenAI 兼容 API（`baseUrl` 可配置）
- 请求格式：标准 Chat Completion 请求体
- 流式响应：SSE → 主进程转发 → preload `onChunk` → ai-store 拼接
- 脱敏（F7.9）：发送前通过 `redact.ts` 摘除文档中的敏感元数据

### 5.3 密钥存储

- 使用 `electron.safeStorage.encryptString()` 加密存储
- 解密后的密钥仅存在于请求构造时，不写入配置 JSON 或日志
- `secretStatus` 仅返回 `{ hasKey: boolean }`，不返回密钥本身

## 7. 安全基线

| 层面 | 措施 |
|------|------|
| 渲染进程 | `sandbox: true`, `nodeIntegration: false`, `contextIsolation: true` |
| Preload | `contextBridge.exposeInMainWorld` 仅暴露白名单方法 |
| CSP | `script-src 'self'`, `style-src 'self' 'unsafe-inline'`, 无 `unsafe-eval` |
| 外部链接 | 白名单协议 (`http:`, `https:`, `mailto:`) 交系统浏览器 |
| IPC 载荷 | 所有入站请求经 Zod `safeParse` |
| 文件路径 | 路径授权集合 `grantedPaths`，未授权路径拒绝读写 |
| 日志 | 不记录 API 密钥、文档正文、完整用户路径 |
| API 密钥 | `safeStorage` 加密，不入 JSON 配置或日志 |
