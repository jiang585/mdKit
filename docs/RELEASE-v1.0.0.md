# MD工具箱 v1.0.0 — 发布说明

> 发布日期：2026-07-27  
> 编写：opencode (deepseek-v4-flash)

---

## 概述

MD工具箱是一款轻量、高性能的 Markdown 编辑与预览桌面应用（Electron + React + CodeMirror 6 + unified），面向开发者、技术写作者和知识管理用户，提供"所见即所得"的实时编辑体验。

---

## 新特性

### 编辑

- CodeMirror 6 编辑器内核，Markdown 语法高亮
- 多标签页支持，标签间切换保留编辑状态（撤销栈、选区、滚动位置）
- 行号显示、自动换行、字体大小可调
- 快捷键与菜单命令（新建/打开/保存/Ctrl+Z 撤销等）

### 预览

- 实时 Markdown 渲染（remark-parse + remark-gfm + remark-math）
- LaTeX 数学公式（KaTeX，行内 `$...$` 与块级 `$$...$$`）
- GFM 扩展语法（表格、任务列表、删除线、脚注）
- 代码块语法高亮（highlight.js，60+ 语言）
- 编辑后预览滚动位置保持
- 编辑区光标在预览区高亮同步

### 主题

- 4 套内置主题：浅色默认 / 纸墨浅色 / 深色默认 / 海蓝深色
- 编辑区与预览区可独立设置主题或联动
- 支持导入自定义主题 JSON

### 布局

- 分屏/纯编辑/纯预览三种模式
- 分屏比例拖拽调整，双击复位 50%
- TOC 目录导航面板
- AI 助手对话面板

### 导出

- 导出为独立 HTML（含 KaTeX 样式与字体）
- 导出为 PDF（Electron printToPDF）

### 文件

- 打开/新建/保存/另存为 Markdown 文件
- 文件拖拽打开
- 最近文件列表
- 自动保存（可配置间隔）
- 崩溃恢复草稿

### AI 桥接层

- 兼容 OpenAI 协议的对话 API
- 对话模式与文档编辑模式
- Diff 预览与逐条接受/拒绝
- 多模型配置切换
- 敏感信息脱敏

### 其他

- Mermaid 图表渲染（按需加载）
- 图片内联预览（本地文件 + 远程 HTTPS）
- 外部链接安全拦截

## 修复内容

v1.0.0 正式发布前由 opencode (deepseek-v4-flash) 完成一轮全面的故障诊断与修复：

### 致命故障

| 问题 | 原因 | 修复 |
|------|------|------|
| 全部 IPC 功能不可用 | Preload sandbox 无法加载 `zod`（externalizeDepsPlugin 标记为外部） | `electron.vite.config.ts` 中将 `zod` 加入 exclude |
| 渲染进程启动异常，欢迎页不渲染 | Ajv 动态代码生成被 CSP `script-src 'self'` 拦截 | 主题校验从 Ajv 替换为 Zod，移除 `ajv` 依赖 |
| 预览区始终空白 | Worker 使用 DOM 入口（`document.createElement` 在 Worker 中不可用） | 强制 Vite 使用非 DOM 入口并增加主线程降级 |

### 配置与测试

- 修复 ESLint 配置错误导致的 184 个误报
- 修正 `tsconfig.web.json` 类型声明缺失
- 修正沙盒和 E2E 脚本配置
- 修正 E2E 数据污染和授权绕过问题
- 修正性能基准测试的字节计算和阈值
