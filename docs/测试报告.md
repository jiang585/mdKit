```powershell
# 类型检查
npm run typecheck

# 代码规范
npm run lint

# 单元/组件/集成测试（不含性能）
npm test

# 性能基准
npm run bench

# 离线沙盒
npm run test:sandbox

# 端到端测试（先 build）
npm run e2e

# 对打包产物执行 E2E
$env:MDKIT_E2E_EXECUTABLE = Resolve-Path 'release/1.0.0/win-unpacked/MD工具箱.exe'
npx playwright test -c tests/e2e/playwright.config.ts
```

## 5. 未覆盖项

| 项 | 原因 | 建议 |
|----|------|------|
| AI 在线对话 | 需要有效 API 密钥和网络 | 手动配置 profile 后用 `npm run e2e` 覆盖 |
| Windows 10 / 11 双平台 | 仅在本机 Windows 11 测试 | CI 配置矩阵运行 |
| 多显示器 DPI 缩放 | 未专项测试 | 手动验证或添加 Playwright 视口参数 |
| 1MB 文档性能目标 | 当前实测 ~4.6s vs 目标 300ms | 见 3.4 节优化方向 |
