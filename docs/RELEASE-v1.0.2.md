# MD工具箱 v1.0.2

## 🐛 问题修复

本版本修复预览端 HTML 兼容、本地图片加载与视图切换相关问题（含未单独发布的 1.0.1 修复）。

### 预览渲染

- **内嵌 HTML 样式丢失**：`<span style="color:…">` 蓝色重点、`<b>` 加粗、`<font color>` 等内嵌 HTML 现可正确呈现。原先渲染管线直接丢弃全部原始 HTML，现改为 `rehype-raw` 解析后再经 `rehype-sanitize` 消毒。
- **HTML 表格整体不显示**：源码中的 `<table>`（含 `colspan` / `rowspan`、单元格样式）完整渲染，不再只剩章节标题。
- **安全性保持**：`<script>`、内联事件（`onclick` 等）、`javascript:` 协议依然全部过滤；`style` 属性按 CSS 属性白名单过滤，拒绝 `url()` / `expression` / 定位类属性；`<style>` 块整体丢弃。

### 本地图片

- **Windows 下本地图片破图**：WebView2 只能以 `http://mdkit-doc.localhost/` 形式访问自定义协议，原 `mdkit-doc://` 地址在 Windows 上必然失败，现已按平台生成正确地址。
- 新增支持盘符绝对路径（`C:/…`、`C:\…`）、`file:///` URL、反斜杠相对路径（`..\img\a.png`）以及内嵌 HTML `<img>` 的相对路径。
- 文件名含非法百分号编码（如 `100%.png`）不再导致整页渲染失败。
- 本地图片协议拒绝含 `..` 的路径；Windows 下目录白名单比对大小写不敏感。

### 视图切换

- **纯预览切回分屏后编辑区内容消失**：纯预览模式下编辑器改为隐藏而非销毁，切回分屏时文本、撤销历史与光标位置完整保留。
